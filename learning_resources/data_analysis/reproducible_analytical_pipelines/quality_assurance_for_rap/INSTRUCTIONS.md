# **QA for RAP ** - Instructions for using markdown and html files
This document provides instructions on how to use the markdown and html provided for the **QA for RAP** learning resource.

## Files and locations
The **markdown** files for this unit can be found directly in the `book`folder within this unit's directory.
The **html** files for this unit can be found directly in the `book/_build/html`folder within this unit's directory.
Both folders contain the same set of example files, but in different formats. Choose the appropriate folder based on your preferred programming language.

## Viewing the files
To view the markdown files, you can use any text editor or a markdown viewer. Within the `book` folder open the desired markdown file to read its contents.

To view the html files, open the desired html file in a web browser. You can navigate to the `book/_build/html` folder and double-click the html file to open it. It is recommended to open the `_build/html/intro.html` file first to get an overview of the content.

## Troubleshooting
If you encounter any issues running the code snippets, consider the following troubleshooting steps:
- Ensure you have followed the setup instructions in the [README.md](../../../README.md) file including `pip install -r requirements.txt`.
- Run code from top to bottom to ensure all dependencies are met.
- Restart the notebook kernel and clear all outputs (at the top of the notebook, select "Kernel" > "Restart & Clear Outputs").
